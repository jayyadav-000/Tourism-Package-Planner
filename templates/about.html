ABOUT WANDERLY

Good trips begin
with good planning.

Wanderly is a Tourism Package Planner built to make discovering, comparing and reserving trips simple.

THE IDEA

One place for
the whole journey.

This academic project demonstrates how a relational database can support a practical travel-planning workflow. Travelers can explore destinations, review package details, create bookings and track reservations. Administrators can maintain package inventory and manage booking status.

Its focus is clarity: structured information, connected records and a straightforward experience from discovery to booking.

UNDER THE HOOD / DBMS

A connected system,
not disconnected lists.

01

Users

Stores customer and admin accounts with role-based access.

02

Destinations

Stores destination identity, state, country and seasonal information.

03

Packages

Links each travel package to a destination through a foreign key.

04

Bookings

Connects customers with packages, travel dates and traveler counts.

05

Payments

Stores a payment preference and demo payment status for each booking.

06

Reviews

Stores a customer's rating and feedback for a package.

Database: SQLite · Backend: Python Flask · Frontend: HTML, CSS and JavaScript · Payment processing is not connected.
